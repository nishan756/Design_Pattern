Builder হলো একটি ক্রিয়েশনাল ডিজাইন প্যাটার্ন যা বড় কোন অব্জেক্টকে ভেঙ্গে ভেঙ্গে তৈরি 
করে আলাদা মেথডের মাধ্যেমে। 

সমস্যা ঃ 
------
ধরা যাক , এমন কোন ক্লাস তৈরি করেছি যার অব্জেক্ট ইনিশিয়ালাইজ করতে অনেকগুলো আরগুমেন্ট লাগবে। 

এবং সেই ক্লাসকে অন্য ক্লাসে ইনহেরিট করেছি অথবা অব্জেক্ট তৈরি করেছি। 

এরপর যদি মেইন / প্যারেন্ট ক্লাসের কন্সট্রাক্টর মেথডে নতুন কোন প্যারামিটার যোগ করি তবে সেই ক্ষেত্রে

অন্য ক্লাসে ইনহেরিট করা বা অব্জেক্ট তৈরি করা প্রতিটি জায়গায় আরগুমেন্ট পাস করতে হবে। 

যদি কোড আপডেট না করা হয় তাহলে সিস্টেম ভেঙ্গে পড়তে পারে। তাই Builder ব্যাবহার করা হয়। 

Builder এর কাজ হচ্ছে আলাদা মাল্টিপল মেথডের মাধ্যেমে অব্জেক্ট তৈরি করা। 

কাজের ধাপ ঃ 
১) প্রথমে মেইন ক্লাস তৈরি করতে হবে এবং কন্সট্রাক্টর মেথডে ডিরেক্ট প্যারামিটার না নিয়ে 
builder object নিতে হবে।

২) পরে builder object এর প্রোপার্টি দিয়ে অব্জেক্ট ইনিশিয়ালাইজ করতে হবে। 

example : 
---------

class UserBuilder {

    String name;
    String username;
    String email;
    String password;

    public UserBuilder setName(String name){this.name = name;return this;}

    public UserBuilder setUsername(String username){this.username = username;return this;}

    public UserBuilder setEmail(String email){this.email = email;return this;}

    public UserBuilder setPassword(String password){this.password = password}
}

class User{

    private String name;
    private String username;
    private String email;
    private String password;

    public User(UserBuilder builder){

        this.name = builder.name;
        this.username = builder.username;
        this.email = builder.email;
        this.password = builder.password;
    }

    @Override 
    public String toString(){

        System.out.println("Name : "+name+"\nUsername : "+username+"\nEmail : "+email);

    }
}


public class Main {

    public static void main(String[] args){

        UserBuilder builder = new UserBuilder();

        builder.setName("Ata Alahy Nishan")
        .setUsername("nishan")
        .setEmail("aanishan339@gmail.com")
        .setPassword("nishan")

        User user = new User(builder);

        user.toString();
        
        Output : 
        Name : "Ata Alahy Nishan"
        Username : "nishan"
        Email : "aanishan339@gmail.com"
    }
}
