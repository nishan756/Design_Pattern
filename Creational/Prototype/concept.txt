Shallow Copy vs Deep Copy
-------------------------

Immutable Object : Immutable object হলো এমন অব্জেক্ট যা তৈরি হওয়ার পরে ইন্টার্নালি চেঞ্জ করা যায় না। 

Mutable Object : Object তৈরি হওয়ার পরেও চেঞ্জ করা যায়।

Shallow Copy তে immutable object normally copy হয়ে যায়, কিন্তু mutable object এর ক্ষেত্রে 
একই ভ্যালু শেয়ার করতে পারে। অর্থাৎ , যদি কোন অব্জেক্ট এর মধ্যে পরিবর্তন নিয়ে আসা হয় তাহলে
অন্য অব্জেক্ট এও চেঞ্জ হয়ে যাবে। 

Deep copy তে mutable object ও normally copy হয়ে যাবে। অর্থাৎ , কোন অব্জেক্ট পরিবর্তন
করলে অন্য কোন অব্জেক্ট এ প্রভাব পড়বে না। 

solution : 
নতুন অব্জেক্ট তৈরি করে কপি করতে হবে। 

example : 

public interface ProtoType<T> {

    public T clone();

}

public class GameCharacter implements ProtoType<GameCharacter>{

    private String name;
    private String weapon;
    private int attackPower;

    public GameCharacter(String name , String weapon , int attackPower){

        this.name = name;
        this.weapon = weapon;
        this.attackPower = attackPower;
    }

    private GameCharacter(GameCharacter gbc){

        this.name = gbc.name;
        this.weapon = gbc.weapon;
        this.attackPower = gbc.attackPower;

    }

    @Override
    public GameCharacter clone(){
        return new GameCharacter(this);
    }
}


public class Main{

    public static void main(String[] args){

        GameCharacter gbc1 = new GameCharacter("Nishan" , "AK47" , 1000);

        GameCharacter gbc2 = gbc1.clone();

        /* 
        যখন gbc1.clone() কল করছি তখন clone() method private constructor() 
        method কে কল করে this(gbc) কে আরগুমেন্ট হিসেবে পাঠাচ্ছে এবং নতুন অব্জেক্ট তৈরি করে 
        gbc2 reference এ স্টোর করছে।  

        */

    }
}
